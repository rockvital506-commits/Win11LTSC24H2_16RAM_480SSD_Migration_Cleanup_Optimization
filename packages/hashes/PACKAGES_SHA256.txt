# Заполняется в окне сети (пакетный bootstrap) и вручную — для офлайн-компонентов с носителя F:.
# Бинарники в Git не хранятся (AR-804).

# --- winget-пакеты (заполняется Invoke-PackageSync.ps1 -ResolveVersions) ---

# <SHA256>  F:\VM\VMware-Workstation-Pro.exe          (гипервизор, ADR-0002)
# <SHA256>  F:\TOOLS\Audit\coreinfo64.exe            (перекрёстная проверка P/E, ADR-0010)
# <SHA256>  F:\TOOLS\Partitioning\DiskGenius_Portable (разметка, Stage 1)
# <SHA256>  F:\TOOLS\Backup\                         (резервное копирование)
