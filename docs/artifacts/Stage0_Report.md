## 1. Контекст и цель этапа

Stage 0 README (§2.1) требует зафиксировать структуру проекта и правила бесконфликтной работы до генерации кода автоматизации. Задачи этапа:

1. подтвердить стабильность связи с GitHub (чтение и запись);
2. утвердить топологию каталогов под три домена: твики ядра/реестра, установка пакетов (winget), DevOps-окружение (WSL2/Hyper-V, архитектура P+E);
3. зафиксировать свод правил автоматизации, включая требования к кодировкам, окончаниям строк и запрет самостоятельного удаления файлов.

Утверждение владельцем: `1-A`, `2-да`, `3-перенос в docs/research/`, `4-tweaks/packages/devops согласовано + tests/ включить`.
