---

## 1. Контекст и цель этапа

Stage 3 — единственный этап, на котором хост получает доступ во внешний мир до цементирования контура (README §4.5). Цель: получить актуальные накопительные пакеты 24H2 (включая обновлённые бинарники подсистемы `VirtualMachinePlatform`, необходимые для WSL2 и VMware через WHP), не допустив при этом драйверного дрейфа и установки вендорского ПО ASUS. По завершении — вернуть систему в полную изоляцию перед Stage 4.
