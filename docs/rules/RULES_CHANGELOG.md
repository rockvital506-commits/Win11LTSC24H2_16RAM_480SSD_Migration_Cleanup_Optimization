## RULES_VERSION 1.0.0 — 2026-10-01

| Поле | Значение |
|---|---|
| Тип | Первичная фиксация свода (MAJOR) |
| ADR | `ADR-0009-automation-rules-baseline.md` |
| Одобрение владельца | 2026-10-01 (решения: 1-A, 2-да, 3-перенос в `docs/research/`, 4-включить `tests/`) |
| Затронутые правила | AR-101 … AR-906 (все группы, первично) |

**Что зафиксировано:**

1. **AR-1xx — кодировки/EOL.** Утверждена матрица «кодировка по классу файла»: `.ps1` — UTF-8 **с** BOM; `.xml` (unattend/ventoy) — UTF-8 **без** BOM; `.bat/.cmd/.vbs/.inf` — ASCII-only; `.reg` — UTF-16LE; `.md/.json/.yaml` — UTF-8 без BOM, LF.
   *Причина:* прямое противоречие между требованием PowerShell 5.1 (BOM обязателен) и парсером WinPE `setup.exe` (BOM недопустим; зафиксировано в `docs/research/step1.md`). Единая политика «BOM везде» технически неисполнима.
2. **AR-2xx — безопасность.** Введён запрет самостоятельного удаления/переименования/перемещения файлов (AR-201/AR-202) и протокол `GATE_DELETE`.
3. **AR-3xx.** Введены идемпотентность, режим `-Audit`/`-WhatIf`, бэкап-перед-изменением, коды возврата, обязательный verification-блок.
4. **AR-4xx.** Введены требования к шапке скрипта, совместимости с PowerShell 5.1 (запрет тернарников и `??`), запрет интерактивности и алиасов.
5. **AR-5xx / AR-6xx / AR-7xx.** Введены доменные правила для `tweaks/` (манифесты, а не ad-hoc `reg add`), `packages/` (winget-first, lock-файл, фиксированные версии) и `devops/` (WSL2 + WHP, P+E-политика, изоляция кэшей).
6. **AR-8xx.** Введены правила Git-гигиены, включая лимит AR-804 на крупные бинарники.
7. **AR-9xx.** Введён процессный контур: DoD, Pester, обязательный прогон валидатора, ограничения AI-агента.
