## 1. Состав

```
C:\Vitality\
├── .vitality.json      (маркер: версия схемы, время UTC, SHA256 манифеста)
├── bin\               исполняемые модули рантайма (офлайн с F:, не в Git — AR-804)
├── config\            конфигурация машины; секреты — отдельными файлами (STRUC_009)
├── logs\              журналы; ротация; в Git не коммитятся (STRUC_008)
├── state\             состояние, локальные индексы, очереди
├── workspace\         рабочие каталоги проектов (крупные данные — на D:)
└── backup\            локальные слепки конфигурации (PAT-19)
```

Перечень каталогов и правила — в `runtime/manifests/RuntimeManifest.json`; документ описывает контракт,
а не заменяет манифест (AR-501: правки — в одном месте).

## 2. Модель прав

| Принципал | Права | Область |
|---|---|---|
| Владелец (пользователь `devops`) | `FullControl` | по наследованию от создателя |
| `NT AUTHORITY\SYSTEM` | `FullControl` | `C:\Vitality\` целиком |
| `BUILTIN\Administrators` | `ReadAndExecute` | `C:\Vitality\` и `config\` |

Правила: **Deny-записи в этом домене не применяются** — запрет SYSTEM принадлежит контуру защиты Stage 6
(`ADR-0003`, PAT-11) и на рабочие каталоги не распространяется, иначе владелец не сможет обслуживать среду.
Права применяются только по флагу `-ApplyAcl` (AR-204, AR-506) и проверяются чтением `icacls`.

## 3. Маркер развёртывания

`.vitality.json` — ключ идемпотентности (AR-301):

```json
{ "schemaVersion": "1.0.0", "deployedAt": "2026-10-01T00:00:00Z", "manifestSha256": "<SHA256>", "host": "<COMPUTERNAME>" }
```

Совпадение `manifestSha256` с текущим манифестом означает «развёрнуто, изменений не требуется».
Расхождение — сигнал к повторному развёртыванию (без удаления существующего, AR-201).

## 4. Размещение данных

| Тип данных | Место | Основание |
|---|---|---|
| Код, конфигурация, состояние | `C:\Vitality\` | README §1.3 |
| Крупные данные, кэши, тома контейнеров, диски ВМ | `D:` (`D:\Docker`, `D:\VM`, `D:\Projects`) | `SC_SSD_LONGEVITY` |
| Инструменты | `D:\GD_Tool\` | README §1.3, Stage 6 |
| Бэкапы этапов | `backups/` рабочей копии репозитория | AR-308, PAT-19 |

Порог предупреждения по объёму `C:\Vitality\` — 5 GiB (`sizeWarningGiB` в манифесте): превышение
означает, что крупные данные уехали на системный диск.

## 5. Развёртывание и верификация

```powershell
# Проверка предусловий и состава без изменений
pwsh -File ./scripts/Stage8_Runtime_Deploy.ps1 -Audit

# Развёртывание (создание каталогов и маркера), права — отдельным флагом
pwsh -File ./runtime/bootstrap/Deploy-Runtime.ps1
pwsh -File ./runtime/bootstrap/Deploy-Runtime.ps1 -ApplyAcl

# Верификация только на чтение
pwsh -File ./runtime/bootstrap/Assert-RuntimeState.ps1 -ExportReport ./docs/artifacts/Stage8_runtime.md
```

## 7. Ограничения

- Агент не размещает бинарники и не включает задачи рантайма: это действия владельца (AR-204, AR-804).
- Автономное удаление в `C:\Vitality\` запрещено (AR-201); изменения — через манифест и `Recovery_Procedure.md`.
- Откат: каталог обслуживается процедурой восстановления (PAT-19), отдельного «uninstall» не предусмотрено.
