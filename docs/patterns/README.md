# docs/patterns/ — Верифицированные паттерны

Реестр паттернов проекта: `PAT-INDEX.md`. Каждый паттерн описывается отдельным файлом по шаблону `templates/Pattern-template.md`.

| Файл | Содержание |
|---|---|
| `PAT-INDEX.md` | Реестр всех паттернов: ID, имя, этап, статус, документ, связанные ADR/правила |
| `PAT-NN-<NAME>.md` | Описание паттерна: контекст, решение, реализация, верификация, ограничения, альтернативы |

**Правила:** §3.4 README (реестр), PAT-NEW-7 (документирование схем), AR-503 (каждый твик ссылается на паттерн). Паттерны с недопустимой для проекта механикой (подписанные драйверы: minifilter, registry callback, WFP callout) в реестр не включаются.
