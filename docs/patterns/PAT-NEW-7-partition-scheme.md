## Контекст

Схема разметки — необратимый параметр стенда (SC_FACTORY_RESET_CAPABLE требует воспроизводимости). Если геометрия существует только «в голове инженера» или в скриншотах DiskGenius, то при повторном развёртывании невозможно ни воспроизвести раскладку, ни доказать, что текущая конфигурация соответствует утверждённой. Дополнительно часть параметров (выравнивание, кластер, fsutil) не видна визуально и требует инструментальной проверки.

## Решение

Схема разметки документируется в репозитории и проверяется скриптом. Обязательный состав:

| Артефакт | Содержание |
|---|---|
| `docs/storage/partitioning_research.md` | Обоснование выбора выравнивания, размеров, ФС, кластеров; открытые пункты и риски |
| `docs/storage/C_drive_schema.md`, `D_drive_schema.md` | Табличная схема разделов + целевая runtime-структура каталогов |
| `ADR-0007` | Решение и альтернативы, критерии верификации V1–V7 |
| `F:\BACKUPS\` | Резервные копии таблиц разделов до и после разметки + SHA256 |
| `scripts/Stage1_DiskGenius_Partition.ps1` | Read-only проверка: типы, размеры, ФС, кластеры, выравнивание, ntfs-параметры |
| `docs/artifacts/Stage1_Report.md` | Фактические результаты: модель устройства, состояние прошивки, результаты V1–V7 |

Формат таблицы разделов (единый для всех схем):

| # | Тип | ФС | Размер | Кластер | Монтирование | Назначение |
|---|---|---|---|---|---|---|

## Верификация

```powershell
pwsh -File ./scripts/Stage1_DiskGenius_Partition.ps1 -ExportReport ./docs/artifacts/Stage1_partition_verify.md
```

Критерий: `ИТОГ: PASS` и совпадение фактических значений с таблицами `docs/storage/*`. Любое расхождение — стоп (`GATE_PARTITIONING`), а не «правка» схемы под факт.

Периодичность повторной проверки: перед Factory Reset (Sysprep-циклом), после замены накопителя, при подозрении на изменение геометрии.

## Ограничения и риски

- Скрипт **ничего не изменяет**: это проверка, а не разметка (AR-204 — деструктивные операции не автоматизируются без отдельного решения).
- Проверка кластеров и `fsutil` возможна только на установленной ОС (в WinPE часть данных недоступна) — фиксируется как WARN.
- Значения размеров проверяются с допуском (служебные области GPT и округление ёмкости производителем).

## Альтернативы

| Вариант | Причина отклонения |
|---|---|
| Хранить схему только в ADR | ADR неудобен для оперативного использования инженером; нет целевой runtime-структуры |
| Скриншоты DiskGenius | Не reproducible, не diff-ятся, не проверяются машинно |
| Только скрипт без документов | Нарушает §3.1 README («нет документации = нет коммита») и SC_FACTORY_RESET_CAPABLE |
