# runtime/manifests/ — Манифесты рабочей среды

| Файл | Назначение |
|---|---|
| `RuntimeManifest.json` | Единственный источник состава `C:\Vitality\`: каталоги, правила прав, порог объёма, перечень проверок. До `S8-OPEN-1` — статус `PROPOSED` |

Правки вносятся только в манифест (AR-501, ADR-0017); после изменения состава маркер `.vitality.json`
считается устаревшим, и `Deploy-Runtime.ps1` создаёт недостающие каталоги, не трогая существующие (AR-201).
