# compose — сценарии окружений

`dev-stack.yaml.template` — типовой локальный стек разработки (PostgreSQL + Redis) для проверки
контура WSL2/Docker. Шаблон, а не рабочий файл (STRUC_010): копируется в проект как `compose.yaml`.

Правила:

- тома — только на `/mnt/d/Docker/volumes` (AR-707: размещение volumes на `C:` запрещено);
- порты публикуются на `127.0.0.1` — наружу контейнеры не смотрят (станция офлайн-ориентирована);
- секреты — файлом (`./secrets/pg_password.txt`), хардкод пароля запрещён (NC_HARDCODED_SECRETS);
- образы фиксируются тегом версии (`postgres:16-alpine`), плавающий `latest` запрещён.
