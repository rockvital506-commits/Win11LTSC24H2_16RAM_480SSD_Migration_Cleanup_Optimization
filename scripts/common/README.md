# scripts/common/ — Общие модули

Инфраструктурные модули без предметной логики. Предметные операции (реестр, ACL, winget, WSL) здесь размещать запрещено.

| Планируемый модуль | Назначение |
|---|---|
| `Logging.psm1` | Единый формат логов (ISO-8601 UTC), транскрипты в `logs/`, коды возврата (AR-305, AR-306) |
| `Backup.psm1` | Бэкап-перед-изменением: реестр/службы/BCD + манифест SHA256 (AR-304, PAT-20) |
| `Verification.psm1` | Обвязка verification-блока, markdown-отчёт UTF-8 без BOM + LF (AR-101, AR-307) |
| `Guard.psm1` | Allow-list путей (AR-206), проверка «не запираем ли сами себя» перед ACL (AR-506) |

**Статус:** все четыре модуля реализованы (Stage 4); используются оркестратором и доменными скриптами.

Все модули — UTF-8 с BOM, совместимость с Windows PowerShell 5.1 (AR-403).
