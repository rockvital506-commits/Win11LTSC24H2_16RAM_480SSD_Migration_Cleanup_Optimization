# scripts/common/ — Общие модули

Инфраструктурные модули без предметной логики. Предметные операции (реестр, ACL, winget, WSL) здесь размещать запрещено.

| Планируемый модуль | Назначение |
|---|---|
| `Logging.psm1` | Единый формат логов (ISO-8601 UTC), транскрипты в `logs/` (AR-305) |
| `Backup.psm1` | Бэкап-перед-изменением: реестр/службы/ACL/BCD + манифест SHA256 (AR-304) |
| `Verification.psm1` | Обвязка verification-блока, коды возврата (AR-306, AR-307) |
| `Guard.psm1` | Allow-list путей (AR-206), проверка «не запираем ли сами себя» перед ACL (AR-506) |

Все модули — UTF-8 с BOM, совместимость с Windows PowerShell 5.1 (AR-403).
