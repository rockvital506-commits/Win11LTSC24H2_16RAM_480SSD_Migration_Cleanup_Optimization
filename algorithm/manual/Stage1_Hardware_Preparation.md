## Цель

Подготовить аппаратный и прошивочный слой **до** разметки накопителя: сохранить старую систему, зафиксировать состояние BIOS, исключить вмешательство вендорского ПО ASUS и убедиться, что WinPE и DiskGenius видят NVMe.

> ВНИМАНИЕ: разметка (auto-часть Stage 1) уничтожает данные. Настоящий документ должен быть выполнен полностью, включая бэкап (§4.5 README: «BACKUP OLD SYSTEM: ДО Stage 1»).

## Предусловия

| # | Требование |
|---|---|
| 1 | USB-носитель F:\ (Ventoy 1.1.10) с ISO WinPE (Strelec 2026.02.05) и ISO Windows 11 LTSC IoT 24H2 в `/ISO/` |
| 2 | `F:\TOOLS\Partitioning\DiskGenius_Portable` доступен из WinPE |
| 3 | Носитель для бэкапа старой системы (внешний диск или `F:\BACKUPS\`, свободно ≥ объёма пользовательских данных) |
| 4 | Заряд батареи ≥ 50 % или питание от сети на всё время работ |

## Шаги

### Шаг 0. Бэкап старой системы (обязательно)

1. Загрузиться в WinPE с Ventoy.
2. Сохранить пользовательские данные и (при возможности) образ старого системного раздела на носитель из предусловия 3.
3. Сформировать манифест SHA256 сохранённых файлов и положить его рядом с бэкапом.
4. Зафиксировать в отчёте: путь бэкапа, объём, дату, контрольную сумму.

### Шаг 1. Настройки BIOS/UEFI

1. Войти в BIOS клавишей **F2** (ASUS Vivobook).
2. **ASUS Software Update / ASUS App Deployment → Disabled.** Обоснование: ACPI-таблица WPBT принудительно внедряет `AsusUpdateCheck.exe`/`AsusAppService.exe` и разворачивает утилиты MyASUS даже без сети (см. `docs/research/anchor1.md`).
3. **Проверить режим накопителя (Intel VMD/RST) — пункт `OPEN-2`.** Если VMD включён, установщик Windows может не увидеть NVMe. Решение (отключить VMD либо интегрировать IRST-драйвер) принимается **до** разметки и фиксируется в отчёте.
4. **Зафиксировать состояние Secure Boot и режима загрузки (UEFI/Legacy) — пункт `OPEN-3`.** Изменение этих параметров без ADR запрещено; на данном шаге — только чтение и протоколирование.
5. Порядок загрузки: USB-носитель первым; Fast Boot — по желанию (не влияет на схему).
6. Сохранить настройки и выйти.

### Шаг 2. Протоколирование стенда

Записать в `docs/artifacts/Stage1_Report.md` (раздел «Исходное состояние»):

| Параметр | Значение |
|---|---|
| Модель ноутбука (`DEVICE_MODEL`) | |
| Версия и дата BIOS | |
| Состояние Intel VMD/RST | |
| Состояние Secure Boot | |
| Модель NVMe и версия прошивки | |
| Серийный номер накопителя | |

### Шаг 3. Загрузка в WinPE и проверка видимости NVMe

1. Загрузиться с Ventoy → WinPE (Strelec).
2. Открыть DiskGenius.
3. Убедиться, что NVMe-накопитель **виден** и имеет заводскую таблицу разделов.
4. Если накопитель не виден — вернуться к шагу 1.3 (`OPEN-2`). Разметку не начинать.

## Критерии выхода

| # | Критерий |
|---|---|
| 1 | Бэкап старой системы создан, манифест SHA256 сформирован |
| 2 | ASUS Software Update / App Deployment отключены |
| 3 | Состояние VMD/RST и Secure Boot зафиксировано в отчёте |
| 4 | NVMe виден в WinPE/DiskGenius |
| 5 | Данные для отчёта (модель, BIOS, накопитель) собраны |
