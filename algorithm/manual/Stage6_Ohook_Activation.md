## 0. Границы

Это **единственное** окно выхода в сеть на отрезке Stage 6 → Stage 7. Ни один скрипт проекта сеть не поднимает и не
опускает (AR-709). Все действия ниже выполняет владелец вручную; агент завершает работу на подготовке (`P0`–`P4`).

Предварительно должны быть выполнены фазы `P1`–`P4` оркестратора (`Stage6_Immunity_Prepare.ps1`), включая
исключения Defender: **сеть включается уже после того, как контур собран**.

## 1. Порядок

| # | Шаг | Как | Контроль |
|---|---|---|---|
| 1 | Убедиться, что подготовка завершена | `Stage6_preflight.md`: `P0.1`…`P4.1` без FAIL | отчёт |
| 2 | **Включить сеть** | физически: Wi-Fi/Ethernet | — |
| 3 | Дождаться связности | `Test-NetConnection activated.win -Port 443` | `TcpTestSucceeded: True` |
| 4 | Выполнить активацию | утилита Ohook с носителя `F:\TOOLS\Activation\` (в Git не коммитится, AR-804) | код 0 |
| 5 | Проверить статус | `Get-CimInstance SoftwareLicensingProduct \| ? {$_.LicenseStatus -eq 1}` | `LicenseStatus = 1` |
| 6 | **Зацементировать** | Планировщик → `System_Immunity_Core` → «Выполнить»; дождаться кода 0 | `D:\GD_Tool\logs\ImmunityCore.log` |
| 7 | **Выключить сеть** | физически; либо `Disable-NetAdapter` — только вручную | 0 активных адаптеров |
| 8 | Настроить вход | закрепить PIN для `devops` (Windows Hello), проверить вход | — |
| 9 | Верификация | `pwsh -File ./scripts/Stage6_Immunity_Prepare.ps1 -VerifyOnly -VerificationReport ./docs/artifacts/Stage6_immunity.md` | без FAIL |

## 2. Если активация не выполнилась

| Симптом | Причина | Действие |
|---|---|---|
| Нет связи | DNS/прокси | проверить `Test-NetConnection`; при необходимости повторить шаг 3 |
| `LicenseStatus = 0` | активация не применена | повторить шаг 4; при повторной неудаче — не выключать сеть, зафиксировать журнал и **не** запускать `System_Immunity_Core` до успеха |
| Активация слетела после перезагрузки | `H-004` (переживание generalize) | повторить окно: снять замок `Phase=Grant`, включить сеть, активировать, зацементировать |

> **Запрет.** Запускать `System_Immunity_Core` (шаг 6) при неработающей активации нельзя: замки заблокируют
> повторную попытку. Сначала — активация, затем цементирование.
