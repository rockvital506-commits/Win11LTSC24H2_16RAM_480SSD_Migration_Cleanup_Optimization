## 1. Цель

Привести `C:\Vitality\` к составу, объявленному в манифесте: каталоги, маркер развёртывания, права
(по флагу), и подтвердить состояние верификатором. Этап ничего не творит «по памяти» и ничего не удаляет.

## 2. Фазы

| Фаза | Действие | Скрипт | Проверки |
|---|---|---|---|
| `P0` | Предусловия: манифест, allow-list, признаки закрытых Stage 6/7 | `scripts/Stage8_Runtime_Deploy.ps1` | `P0.1`–`P0.3` |
| `P1` | Развёртывание каталогов и маркера, права по `-ApplyAcl` | `runtime/bootstrap/Deploy-Runtime.ps1` | `D0.*`, `D1.*`, `D2.*` |
| `P2` | Верификация только на чтение | `runtime/bootstrap/Assert-RuntimeState.ps1` | `A0.1`–`A2.3` |
| `P3` | Сводный отчёт | оркестратор | `docs/artifacts/Stage8_preflight.md` |

## 3. Идемпотентность

| Ситуация | Поведение |
|---|---|
| Маркер совпадает с манифестом (по SHA256) | Операции не выполняются, `D1.2` = PASS (AR-301) |
| Каталог существует | Не изменяется (AR-201) |
| Каталог отсутствует | Создаётся, `D1.1` фиксирует число созданных |
| Появились посторонние элементы | `D2.1` = WARN, элементы не удаляются; решение владельца |
| Состав `PROPOSED` | Развёртывание требует `-AcknowledgeProposedComposition`, иначе только `-Audit` |

## 4. Откат

| Ситуация | Действие |
|---|---|
| Развёртывание остановлено на `P0` | Ничего не менялось (все проверки до записи) |
| Созданы лишние каталоги | Удаление — только владельцем вручную (AR-201, AR-204) |
| Права применены неверно | Повторный `icacls` по манифесту; снятие — вручную владельцем |
| Требуется полный возврат | `docs/artifacts/Recovery_Procedure.md`, раздел по `C:\Vitality\` |

## 5. Риски

| ID | Риск | Митигация |
|---|---|---|
| `R1` | Состав утверждён без учёта задач владельца | `S8-OPEN-1`: ратификация до реального развёртывания |
| `R2` | Крупные данные оказались на `C:` | `D2.2`/`A2.2` — предупреждение при превышении порога (AR-509) |
| `R3` | Права применены до согласования | `-ApplyAcl` — отдельный флаг (AR-204, AR-506) |
| `R4` | Секрет попал в конфигурацию репозитория | Секреты — файлами в `config\` вне Git (`STRUC_009`) |
| `R5` | Бинарники рантайма попали в Git | Поставка офлайн с `F:`, хэши в `packages/hashes` (AR-804) |
