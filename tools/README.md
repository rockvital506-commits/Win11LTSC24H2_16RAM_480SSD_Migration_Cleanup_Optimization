# tools/ — Сторонние инструменты

Бинарники в Git **не хранятся** (AR-804, ADR-0006). В репозитории — только этот README и хэш-манифесты `SHA256SUMS.txt`.

## Правила

- Бинарники размещаются на `F:\TOOLS\...` и на рабочем диске; в Git — только SHA256 (AR-804).
- Вызов инструментов — по полному пути с версией, не из `PATH` (AR-409).
- Схема версионирования: `tools/<TOOL>/<VERSION>/` (STRUC_006).
- Лимит GitHub — 100 МБ на файл; ISO и установщики не коммитятся ни при каких условиях.
